# Soft-Robot Self-Healing

Research software for soft-robot control, model adaptation, and recovery from damage.

## Repository contents

- `scripts/` — model training, adaptation, evaluation, and plotting.
- `experiment_code/` — experimental analysis and plots.
- `exp_setup_ws/` — ROS 2 controllers, actuation, and recording.
- `sofa/` — simulation examples.

## Usage

Research code; setup depends on the experiment and hardware. See the ROS 2 package READMEs for package-specific instructions.
